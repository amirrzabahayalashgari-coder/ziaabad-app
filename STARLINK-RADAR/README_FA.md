# STARLINK RADAR — Android build

این پوشه محل پروژه دانشگاهی STARLINK RADAR است.

## وضعیت
- پروژه Android/Kotlin با رابط فارسی و نقشه دوحالته (خیابانی/ماهواره‌ای).
- اسکن Wi-Fi فقط شبکه‌های قابل دریافت گوشی را فهرست می‌کند.
- برچسب Starlink صرفاً «قرینه نام شبکه» است و تأیید دیش یا مکان‌یابی دیش نیست.
- موقعیت‌های روی نقشه برای اسکن Wi-Fi، محل گوشی هنگام اسکن هستند؛ نه محل روترهای دیگران.
- ردیابی ماهواره از داده مداری عمومی انجام می‌شود و با مکان‌یابی دیش زمینی فرق دارد.

## افزودن سورس کامل
فایل ZIP نسخه 1.1 را از گفتگوی ChatGPT دریافت و محتویات پوشه `starlink-radar` داخل ZIP را در همین پوشه `STARLINK-RADAR/` قرار بده؛ به‌طوری‌که فایل‌های `settings.gradle` و `app/build.gradle` مستقیماً داخل همین پوشه باشند.

## ساخت APK
پس از قرار گرفتن سورس، workflow با هر push به این پوشه اجرا می‌شود. APK آزمایشی از بخش **Actions → Android APK → Artifacts** قابل دریافت خواهد بود.

برای نصب، APK را روی گوشی دانلود کن و فقط در صورتی نصب کن که ساخت workflow موفق بوده باشد.
