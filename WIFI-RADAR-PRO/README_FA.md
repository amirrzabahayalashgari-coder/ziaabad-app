# STARLINK RADAR — نسخه آزمایشی اندروید

سورس اندروید این نمونه در همین پوشه قرار دارد و با GitHub Actions برای ساخت APK آزمایشی آماده شده است.

## امکانات فعلی
- رابط کاربری فارسی با تم تیره
- درخواست اسکن شبکه‌های Wi‑Fi قابل دریافت توسط گوشی
- نمایش SSID، قدرت سیگنال و فرکانس
- مرتب‌سازی شبکه‌ها بر اساس قدرت سیگنال
- علامت‌گذاری نام‌هایی که واژه Starlink دارند؛ صرفاً به عنوان قرینه ضعیف

## محدودیت علمی
گوشی معمولی سیگنال ماهواره‌ای Starlink در باندهای Ku/Ka را مستقیماً دریافت یا اسکن نمی‌کند. نام شبکه یا قدرت سیگنال، وجود دیش یا مالکیت آن را ثابت نمی‌کند. این برنامه محل دیش یا روتر دیگران را پیدا نمی‌کند.

## ساخت APK
پس از هر تغییر در این پوشه، workflow با نام **STARLINK RADAR Android APK** اجرا می‌شود. در مخزن GitHub به بخش **Actions** بروید، اجرای آخر را باز کنید و پس از موفقیت، فایل `STARLINK-RADAR-debug-apk` را از قسمت **Artifacts** دریافت کنید.

این خروجی debug و آزمایشی است؛ پیش از انتشار عمومی باید روی دستگاه‌های واقعی آزمایش شود.
