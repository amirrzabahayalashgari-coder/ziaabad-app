# فارسی‌نگار AI — موتور محلی و بدون API پولی

این نسخه از faster-whisper استفاده می‌کند. فایل صوتی برای تبدیل به سرویس API پولی ارسال نمی‌شود و هیچ کلید API لازم نیست.

## رایگان بودن
- اجرای مدل روی رایانهٔ خودتان هزینهٔ API و هزینهٔ هاست ندارد.
- در اجرای اول، مدل دانلود می‌شود؛ برای دانلود اولیه اینترنت لازم است.
- پس از دانلود مدل، پردازش صوت به‌صورت محلی انجام می‌شود.
- GitHub فقط کد را نگه می‌دارد و خودش موتور تبدیل صوت را اجرا نمی‌کند.
- اجرای برنامه روی سرور ابری ممکن است هزینهٔ سرور داشته باشد.

## اجرا در ویندوز
1. Python 3.10 یا جدیدتر را نصب کنید.
2. این پوشه را دریافت و استخراج کنید.
3. START-WINDOWS.bat را اجرا کنید.
4. در اجرای اول مدل small دانلود می‌شود.
5. مرورگر را در http://127.0.0.1:5000 باز کنید.

برای استفاده با گوشی، گوشی و رایانه را به یک Wi-Fi وصل کنید و آدرس IP رایانه را با پورت 5000 در گوشی باز کنید.

## مدل‌ها
small برای شروع روی CPU مناسب‌تر است. medium می‌تواند دقت بهتری داشته باشد اما حافظه و زمان بیشتری می‌خواهد. برای تغییر مدل، WHISPER_MODEL را در فایل .env تغییر دهید.

## محدودیت‌ها
سرعت تبدیل به مدل و سخت‌افزار بستگی دارد. برای فایل‌های یک یا دو ساعته حافظه و فضای دیسک کافی لازم است. این نسخه برای استفادهٔ شخصی/شبکهٔ محلی است؛ قبل از انتشار عمومی باید HTTPS، احراز هویت و صف پایدار اضافه شود.
