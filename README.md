# ziaabad-app

## فارسی‌نگار AI — تبدیل صوت فارسی بدون API پولی

نسخهٔ محلی مبتنی بر faster-whisper در پوشهٔ [farsinegar-ai](./farsinegar-ai/README-FA.md) قرار دارد. برای راه‌اندازی در ویندوز، فایل [START-WINDOWS.bat](./farsinegar-ai/START-WINDOWS.bat) را اجرا کنید.

**توجه:** GitHub محل نگهداری کد است و موتور تبدیل را اجرا نمی‌کند. برای استفادهٔ بدون هزینهٔ API، برنامه باید روی رایانهٔ خودتان اجرا شود؛ اجرای آن روی سرور ابری ممکن است هزینهٔ سرور داشته باشد.
