# ZiaAI Online — نسخه عمومی و مدیریت

این شاخه نسخه مستقل آنلاین ZiaAI است؛ شامل رابط عمومی، API پردازش صوت و پنل مدیریت.

## قابلیت‌های پیاده‌سازی‌شده در کد
- رابط فارسی و راست‌چین برای بارگذاری صوت و دریافت متن
- صف ساده پردازش و تقسیم فایل‌های بلند به قطعه‌های ۸ دقیقه‌ای با FFmpeg
- اتصال سمت سرور به Groq Whisper با مدل `whisper-large-v3` و زبان فارسی
- وضعیت پردازش و خروجی متن
- پنل مدیریتی محافظت‌شده با رمز مدیر
- فهرست کاربران/شناسه‌ها، زمان آخرین فعالیت، IP ثبت‌شده و امکان مسدودسازی/رفع مسدودی
- محدودیت اندازه فایل، محدودیت درخواست، ثبت رویدادهای مدیریتی و حذف فایل موقت پس از پردازش

## راه‌اندازی
نیازمند Python 3.11+، FFmpeg و متغیرهای محیطی:
- `GROQ_API_KEY`: کلید API فقط روی سرور
- `ADMIN_PASSWORD`: رمز قوی مدیر
- `DATA_DIR`: مسیر ذخیره‌سازی پایدار (پیش‌فرض ./data)
- `MAX_UPLOAD_MB`: سقف بارگذاری (پیش‌فرض 500)

اجرا:
```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

## استقرار عمومی
فایل `render.yaml` نمونه تنظیم استقرار است. برای نگهداری فایل‌های موقت و پایگاه داده در ری‌استارت‌ها، دیسک پایدار لازم است. قبل از انتشار عمومی، یک سرویس میزبانی با HTTPS و دیسک پایدار انتخاب و متغیرهای محرمانه را در بخش Environment همان میزبان تنظیم کنید. کلید API را هرگز در Git، HTML یا APK قرار ندهید.

## اپلیکیشن اندروید
تا وقتی نشانی HTTPS نهایی سرور تنظیم نشده و تست واقعی انجام نشده، APK عمومی/مدیریتی نهایی قابل انتشار نیست. پس از استقرار، آدرس سرویس در پوسته اندروید تنظیم و از GitHub Actions ساخته می‌شود.

## حریم خصوصی
IP برای امنیت و مقابله با سوءاستفاده ثبت می‌شود و فقط مدیر احراز هویت‌شده می‌تواند آن را ببیند. سیاست پیشنهادی نگهداری IP هفت روز است؛ در این نسخه حذف زمان‌بندی‌شده هنوز نیازمند تنظیم در میزبان است. قبل از ارائه عمومی، متن اطلاع‌رسانی حریم خصوصی و شرایط استفاده را منتشر کنید.


## وضعیت فعلی و موارد لازم پیش از انتشار عمومی
این شاخه یک نمونه اولیه قابل توسعه است، نه سرویس عمومی آماده بهره‌برداری. هنوز روی میزبان واقعی Deploy نشده و تست end-to-end با کلید Groq یا فایل صوتی ۱ تا ۲ ساعته انجام نشده است. پنل مدیریت فعلاً شناسه مرورگر و IP قابل مشاهده برای سرور را نشان می‌دهد؛ شناسه مرورگر به‌تنهایی احراز هویت واقعی نیست و کاربر می‌تواند با پاک‌کردن داده مرورگر شناسه تازه بسازد. برای مدیریت قطعی اشخاص باید ثبت‌نام/ورود حسابی و صف پایدار (مانند Redis) اضافه و آزموده شود. در میزبانی پشت پراکسی ممکن است IP قابل مشاهده، IP پراکسی باشد؛ قبل از فعال‌کردن مسدودسازی IP باید زنجیره پراکسی به‌صورت امن پیکربندی شود. مسدودسازی IP می‌تواند افراد یک شبکه مشترک را هم تحت‌تأثیر قرار دهد.

همچنین وضعیت کارها در حافظه فرایند نگهداری می‌شود؛ با راه‌اندازی مجدد سرور، وضعیت کارهای در حال اجرا از بین می‌رود. برای استفاده عمومی پایدار باید صف و وضعیت کارها به پایگاه داده/صف پایدار منتقل، ورود مدیر دارای انقضا و محدودیت تلاش شود، و تست بار و حریم خصوصی انجام شود. پنل مدیریت در مرورگر قابل نصب به‌صورت Web App است؛ APK مدیریتی هنوز ساخته نشده است.
